# Decisions

One line each: **decision** — why — how to revert. Newest last. Written by the
autonomous v1 build (goal contract of 30 Sep 2026); the owner may reverse any.

- **D1 · Fixture skips go through a `gust-testkit` crate (`skip!`/`skip_unless!`) that writes a ledger; `tests/run-tests.sh` reports them as SKIP and subtracts them from the pass count** — libtest has no runtime skip, so an early return printed `ok` and inflated the pass count — revert: drop `crates/testkit`, restore the `eprintln!("SKIP…"); return;` blocks, point `just test` back at `cargo test`.
- **D2 · `clipboard_live` runs only with `GUST_LIVE_CLIPBOARD=1` (or `GUST_CLIPBOARD_REQUIRED=1`)** — it replaced the real clipboard of whoever ran `cargo test` — revert: remove `live_clipboard_opted_in()` from `need_wayland!`.
- **D3 · `GUST_ALL_REQUIRED=1` turns every fixture skip into a failure; `just test-required` sets it** — the goal asks for one recipe that sets every `GUST_*_REQUIRED`; a single switch cannot miss a newly added gate — revert: delete the recipe and the `all_required()` check.
- **D4 · Lint fixed for the Rust 1.98 toolchain (`is_multiple_of`, `&Path`, one `#[allow(too_many_arguments)]` on the job worker) and the tree `cargo fmt`-ed** — `just lint` was red at 4c2ac56 on this toolchain; the fmt pass is whitespace only — revert: `git revert` the commit.
- **D5 · `tests/lint-qml.sh` strips strings and comments in ONE pass, and allows `indexOf`/`includes`/`valueOf` in bindings** — the two-pass version treated the `//` in `"file://"` as a comment and reported 4 phantom unclosed braces; the three methods read notifying properties so the binding does re-evaluate. A planted missing brace still fails the gate — revert: restore the previous regex block.
- **D6 · A listing reads size/date/mode only for the first 256 rows (plus the row the cursor must land on); other rows are read when they scroll into view (`want_rows`)** — Gust stat'ed all 100k files before settling and lost Flea's own "settled" column (2098 vs 885 ms). A name/kind sort is final on names alone; size/date sorts still read everything first — revert: in `load_current` call `fill_metadata` unconditionally again.
- **D7 · Enter on a file whose mode is not read yet asks for it and refuses this once ("press Enter again")** — the executable bit is what makes a file runnable, and guessing it from the name alone could open a script. A second Enter decides on the real mode — revert: drop the `mode.is_none()` guard in `activate` (not recommended).
- **D8 · The selection's byte total is omitted while any selected row's size is unknown** — a partial sum stated as a total is a wrong number with confidence — revert: sum known sizes only.
- **D9 · Flea's field bench is run from a copy with a 13-line diff that adds Gust as an entrant (`bench/harness/`), plus a stand-in for Flea's private `omarchy-drive env`** — the harness is MIT and its method is the one the goal names; the diff only adds a row, a kill-list entry and a SKIP-if-missing check, so every other entrant is measured exactly as Flea measures it — revert: delete `bench/harness/`.
- **D10 · Preset-dependent and new shortcuts live in one Rust table (`crates/core/src/keymap.rs`) that both the key handler and the `?` key map read** — STATUS claimed Ctrl+1–9 and the code had none; with one table a documented key that does nothing, or a key the map omits, is impossible, and unit tests check for duplicate chords and for trash on a bare key — revert: delete the `key_action` call at the top of Main.qml's shared handler.
- **D11 · Four key presets: Standard, Vim, Mac, Windows; Mac maps Cmd to Ctrl** — Omarchy's window manager owns Super, so a literal Cmd preset would collide with the desktop; Windows makes Backspace go Back as Explorer does — revert: drop the two enum variants (settings keep loading; unknown values fall back to Standard).
- **D12 · Zoom (Ctrl+= / - / 0) scales type and rows in Rows/Columns and tile size in Grid, and is not saved** — Omarchy uses these keys for zoom everywhere; a persistent zoom that survives into the next session surprises more than it helps. Density persists separately in Settings — revert: remove `Tokens.zoom`.
- **D13 · Middle-click a folder opens it in a background tab appended at the end** — browser habit (Flea #219); appending keeps every existing Ctrl+N index stable — revert: remove `Qt.MiddleButton` from the three views.
- **D14 · New file (Ctrl+Shift+N, menu, palette) and templates create with O_EXCL; a template must be a regular non-link file ≤16 MiB read with O_NOFOLLOW|O_NONBLOCK** — never replace a file, never follow a planted link, never hang on a FIFO planted in ~/Templates — revert: delete `crates/ops/src/create.rs` and the `new_file` invokable.
- **D15 · qa.sh's setup and helpers moved to `tests/qa-lib.sh`; new sections live in `tests/qa.d/NN-*.sh` and run alone with `tests/qa-one.sh`** — a 16-minute suite is too slow to see a new test fail first; the full `just qa` still sources every section and stays the gate — revert: concatenate qa-lib.sh and qa.d/* back into qa.sh.
- **D16 · File hashes (SHA-256) are computed only when asked (h in Quick Look), on a worker, cancelled on close; implemented in-tree (`gust-core::hash`) rather than adding a crate** — hashing reads the whole file, so it must never start just because a preview opened; the code is ~150 lines checked against NIST vectors and `sha256sum` at every padding boundary, and adds no dependency to audit — revert: delete `crates/core/src/hash.rs` and the `hash_row` invokable.
- **D17 · The QA probe writes one extra "settle" dump 300 ms after the last one (QA builds only, `GUST_QA_STATE` set)** — geometry such as `cursorPoint` is read when a dump is written, and a list scroll happens after it; the middle-click case clicked a stale point in the full suite — revert: remove the `qaSettle` timer.
- **D18 · Make link and Permissions each hold the one level of undo; undo re-checks dev+inode+mtime (and, for modes, that the mode is still the one Gust set) and refuses otherwise** — AGENTS.md rule for destructive paths; a link replaced by real work, or a mode someone changed again, is left alone with the reason shown — revert: delete `crates/ops/src/attrs.rs` and its invokables.
- **D19 · Permissions never set or clear setuid/setgid/sticky, and skip symlinks** — those bits are a privilege boundary, and chmod on a link changes a file that may live elsewhere; the prompt says why — revert: widen `ModeSpec::parse` (not recommended).
- **D20 · Text colours are held to WCAG on every surface they are drawn on (4.5:1 primary, 3:1 secondary; list, sidebar/hint strip, menus/banners, bar). A failing secondary colour is moved toward the foreground in 5 % steps, only as far as needed** — Omarchy's `dark_foreground` is a terminal colour: 12 of 22 stock themes put it under 3:1, and the white theme's banner hint was 1.9:1 on its menu surface. The smallest lift keeps each theme's hue and keeps secondary text secondary; a theme that already passes is untouched (tested) — revert: remove the `enforce_contrast(&mut t)` call in `load_from_theme_dir`.
- **D21 · Copies onto FAT are checked before a byte is written: any file of 4 GiB or more refuses the whole transfer ("Nothing was copied"); names FAT cannot store get `_` for each bad character and lose trailing dots/spaces, and the card says what was renamed** — failing at 99 % or silently dropping files is the bug class this replaces; refusing everything keeps "copy" meaning all-or-nothing for the user's selection. exFAT gets the name rules only — revert: set `fat_names = false` in `jobs::run`.
- **D22 · Ctrl+L opens the palette in "jump" mode: folders ranked across bookmarks, zoxide (when installed, 2 s cap) and the folders of recent files come first; Tab completes a typed path from the real folder listing** — Flea 0.3.6's folder jump is the reference; candidates are gathered once on a worker when the palette opens and ranked in memory per keystroke, so typing never touches the disk; a network bookmark is never stat'ed from here — revert: make `jump` call `palette.open()`.
- **D23 · `navigate` expands a typed `~/…` and drops a trailing slash** — a typed "~/Projects" was refused as "not a directory", and "/x/" and "/x" were two locations to history and breadcrumbs — revert: remove the two normalisation lines at the top of `navigate`.
- **D24 · Rows gains a Kind column (extension, "folder", "link", or "file"), sortable by its header and from the palette** — sort by kind existed in the engine with no way to reach it (Flea #190); the column shows exactly what the order uses, so the sort is never mysterious — revert: remove `kindCol`/`kindText` from RowsView.qml.
- **D25 · Rubber-band select is a layer above Rows/Grid that refuses any press landing on an item; a plain drag replaces the selection, Ctrl+drag adds, a click on empty space selects nothing** — a press on a row must stay a click or a drag-to-move exactly as before; the band updates on every move so shrinking it unselects — revert: delete the `RubberBand {}` blocks.
- **D26 · STATUS corrected: "Add a place" is partial (no dialog, no mDNS/Tailscale); Ctrl+1–9 now points at the qa step that proves it** — both were over-claims the goal contract called out — revert: n/a (documentation).
- **D27 · Custom actions are TOML files in `~/.config/gust/actions/` with an argv `command` list, run directly (never a shell); `{file}` as a whole argument gets `./` if it starts with `-`; files not owned by the user or group/world-writable are ignored; at most 50 runs per activation** — Strata's most-requested feature, made so a filename can never become a command or an option and another account cannot plant one — revert: delete `crates/core/src/actions.rs` and the two invokables.
- **D28 · The bench copy of Flea's harness uses passwordless `sudo -n` for cache drops instead of reading a sudo password from stdin; `just bench-field` feeds it `/dev/null`** — no password is ever read, piped or held by Gust's tooling, and the disposable bench VM has passwordless sudo; on a machine without it the harness stops with a clear message — revert: restore the two original lines from Flea's `tools/flea-field-bench` (see `bench/harness/gust-entrant.diff`).
- **D29 · Programs run only via "Run…" (right-click, palette), behind a confirmation that names the file and focuses Cancel; they run in the default terminal via `xdg-terminal-exec --hold --dir=<its folder> -- <path>`; a file without an x bit is refused rather than run through a guessed interpreter** — Enter never runs a program (unchanged), a stray Enter in the prompt cancels, and the path is one argv entry — revert: remove the `run` entries from the menu and palette.
