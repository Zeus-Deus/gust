# Gust release notes — unqualified draft

No release publication is authorized by this draft. The current implemented
scope is maintained in the [root README](../../README.md). New backend APIs count
as user features only after app/UI consumption and native acceptance.

Release qualification is pending for the integrated source revision and its
installed artifacts. Record exact source pin, build receipt, architectures,
invoked tests, skips, native journeys and complete supplied theme matrix before
writing release pass claims. Benchmarks, hardware and provider results must come
from their own recorded runs. Historical VM evidence is not a fresh pass.

The source preparation includes immutable archive metadata, runtime-file and
dependency checks, skip-aware required test gates and separate app/model/native
scopes. Those changes improve reviewability; they do not imply a data-loss
warranty, universal undo, absence of UI-thread I/O or current device support.
