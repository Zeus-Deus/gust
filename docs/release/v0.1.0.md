# Gust v0.1.0 — release notes (draft, not published)

The first release of Gust, a fast, calm file manager for Omarchy.

## Highlights

- **Fast.** On Flea's own field bench (same VM, cold cache, medians of 3), the
  folder is listed and settled in 410 ms for 100,000 files and 277 ms for
  2,000 media files. Flea 0.3.7 takes 756 ms and 848 ms. Gust uses 93 MiB
  and 80 MiB of memory (PSS) against Flea's 177 MiB and 186 MiB. On the
  low-end profile (2 CPUs, 2 GiB, software rendering), Gust still settles
  first. Flea's first window is 6–38 ms quicker there and it uses a little
  less memory. `bench/RESULTS.md` gives the numbers and the reasons.
- **Themed by Omarchy.** All 22 bundled themes, live theme switching, and a
  contrast test across every theme.
- **Safe by construction.** Staged atomic copies, a confirmation before every
  destructive action, and an undo that checks it is still undoing the same
  file.

## New everyday features in this release

- Pause and Resume for transfers, on the transfer card. Cancel still works
  while paused.
- Owner… for one or many files: `user`, `:group` or `user:group`. Ctrl+Z
  puts them back.
- Paste an image from the clipboard as a file (PNG, JPEG, WebP, GIF).
- Link here, from a right-button drag.
- Open as administrator, through polkit, in a separate window that is
  clearly marked.
- Copied and cut items are marked in the listing.
- Settings → Tabs at start → Reopen last.

## Fixes

- Folder sizes are worked out only for the folders on screen.
- A drive with nothing to open (such as an empty DVD tray) no longer leaves
  a dead row in the sidebar.
- Clicking the folder you are already in no longer reloads it.
- With two tabs open, the hint strip was pushed below the window.
- The Trash confirmation now names the item that will be moved, even when the
  cursor has wandered away from the selection.
- Sort headers read ▲ for ascending and ▼ for descending.
- Selected text in input fields is readable in every theme. Menus and dialogs
  in light themes use the theme's own background.

## Tested

749 library tests pass (41 skips, each named with its reason). The desktop
qa suite drives the real window with real keys and a real pointer, and every
assert passes. The theme screenshot matrix covers all 22 themes.

## Install

See README. Requires Qt 6 and a Wayland session. Optional helpers are in
`optdepends`.

## Known limits

- MTP/AFC phones, Tailscale and network discovery are not in this release.
- Previews cover text and images. Markdown, audio and PDF previews come
  later.
- Open as administrator needs a polkit agent. Omarchy ships one.
